Graph Overview

The platform has two major runtime surfaces in this release: the API Gateway (proxy) and the Light EMR Adapter (currently optional in the public deployment). Supporting layers include Redis (caching), PostgreSQL/OpenEMR (clinical system), optional identity providers (Keycloak / OAuth2), and observability endpoints (Prometheus).

Current Deployment State

  • Gateway: Active (Railway)
  • Adapter: Fallback mode via gateway routes
  • FHIR Base: Proxied / fallback metadata
  • Identity Providers: Optional / warnings if absent
  • Metrics: /metrics exposed for scraping (histograms for latency)

Planned Enhancements

  1. Adapter deployment parity with gateway
  2. Background job queue (RabbitMQ) activation
  3. Enhanced tracing (OpenTelemetry + B3 propagation)
  4. Fine-grained module feature flags
  5. Secrets manager integration
