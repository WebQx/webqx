How It Works

Opens a WebSocket to the gateway /api/telehealth/ws path and echoes messages. Measures round‑trip latency for pings (text frames).

  • Auto‑ping sends "ping" every 3s
  • Latency = time from send to echo receipt
  • Future: presence + session signaling

Security Considerations

Gateway applies optional token validation and size caps. In production, pair with an auth provider (OIDC) + per-session authorization & rate limiting.
