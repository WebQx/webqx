How It Works

Opens a WebSocket to the gateway /api/telehealth/ws path and echoes messages. Token-based auth (if configured) would reject unauthenticated access; this demo uses open mode.

  • Max message length enforced (5 KB)
  • Structured log entry created server-side
  • Future: presence + signaling for sessions

Security Considerations

Gateway applies optional token validation and size caps. In production, pair with an auth provider (OIDC) + per-session authorization & rate limiting.
