About This Demo

This GitHub Pages space surfaces live data from the Railway deployment at webqx-production.up.railway.app. The light EMR adapter may be running standalone or served via proxy fallback.

  • Health: Gateway /health unified schema.
  • Adapter: /emr/status (fallback returns degraded).
  • Patients: Real patients if adapter active; mock fallback otherwise.
  • Modules: Additional cards exercise headers, env, FHIR, WebSocket, rate limiting, and future transcription.
  • Zero PHI: All content intentionally sanitized / synthetic.
